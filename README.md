# GyroFix

Unofficial gyro firmware patches for GameSir controllers. Not made or supported by GameSir. Use at your own risk.

| Controller | Firmware | Status |
|---|---|---|
| Tarantula Pro 8K PC | V5.02 | Tested |
| G7 Pro 8K | V5.08 | Tested |
| Cyclone 2 | V3.52 | Experimental |

## Download

Grab the latest zip from [Releases](../../releases/latest), unzip the whole thing, open the folder for your controller and follow the README inside it. You need a Windows PC to flash.
